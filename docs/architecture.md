# 第一版：运行与失败契约

状态：首条链路已实现，自动化测试与一次真实模型检索已通过。以下是第一版契约，全面效果评估待继续；已确认产品范围见 [Spec](spec-v1.md)。

## 一条运行流程

```text
CLI 输入 → 扫描 Markdown 变化 → 同步关键词与向量索引
        → 受限 Agent 搜索候选 → 读取原文 → 结果及出处
```

查询先完成资料同步，再进入 Agent 循环。模型提出动作，程序校验参数、范围和预算后执行；搜索与读取可独立于 Agent 验证。文章找回为主，多篇综合回答同样只依据已读取证据。

## 数据与责任

| 内容 | 事实来源与生命周期 |
|---|---|
| 文章 | 本机 Markdown；第一版只读，不由 Agent 改写 |
| 片段、关键词索引与向量 | 可重建派生数据；关联文件、原文位置、内容哈希和编码配置版本 |
| 会话 | 内存保存追问及候选；退出不恢复，读取候选时核对版本 |
| 执行记录 | 保存必要动作、错误、耗时和可获得用量；不作为文章事实，不记录凭据 |

CLI 负责交互与组装；agent 负责受限循环、工具分派与会话；knowledge 负责解析、同步、混合检索、读取和来源；llm 负责对话与 embedding 服务适配。编码模型、维度或切分配置改变时，重建相应向量，禁止混用不兼容索引。

## 失败契约与不变量

| 情况 | 第一版建议行为 |
|---|---|
| 索引同步、文件解析或 embedding 失败 | 结束本次查询并说明失败；不静默使用旧索引或降级为关键词查询。重试复用已成功缓存的编码 |
| 新索引构建中断 | 新版本准备完整后才发布为可查询版本；保留最后完整版本供恢复，但不同步成功不进入查询 |
| 文章修改或删除 | 同步替换或移除对应片段、关键词与向量；原文读取及结果发布前核对本次证据版本 |
| 已读取证据在查询中变化 | 拒绝发布基于旧证据的答案，提示重新查询；结果代表已校验的快照，不保证发布后文件永远不变 |
| 搜索无候选或不足 | 报告未找到足够证据，允许预算内换词补查；不宣称资料一定不存在 |
| 候选难区分或内容矛盾 | 展示候选区别、冲突及出处；必要时追问，不强行给唯一结论 |
| 对话 API 失败、动作无效、超预算或取消 | 明确结束，区分原因；不把异常解释为资料缺失，不发布未经校验的完整答案 |
| 引用不存在或未读取 | 拒绝最终输出；程序验证引用身份与版本，语义是否支持结论仍需案例验收 |

工具仅访问配置允许的资料范围，不提供任意 Shell、文章修改或外部发送。原文中的指令按资料处理，不改变工具授权。默认最多 8 步、单请求 45 秒、整次查询 180 秒，可取消；协议与服务错误直接结束，不自动重试。

## 目录建议与后续边界

第一版采用 cmd/assistant、internal/agent、internal/knowledge、internal/llm 四个边界；工具与会话先留在 agent，索引存储先留在 knowledge。单元测试贴近代码；testdata 保存合成资料，个人文章及生成数据不入仓库。不为每项职责预建独立框架。

后续邮件等长期业务任务独立保存状态，等待用户时结束 Agent 执行；网页和手机复用核心能力。当前不实现长期恢复、通用工作流或插件系统。

已采用 SQLite 与百炼 text-embedding-v4，每批至多 10 条；仅处理 .md，过滤 draft/encrypted。调用记录当前输出 stderr，未持久化。待继续：真实语义案例、相关性与成本调优、持久日志、索引清理；多实例尚未支持。
